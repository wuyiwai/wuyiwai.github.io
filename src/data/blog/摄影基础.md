# 基本概念
### 曝光三要素

- ISO: 
	- 相机对于光线的敏感程度；值越高画面越亮
	- 他只是让相机对于光线更敏感，敏感是有代价的，容易出现噪点，让视频看上去有点脏脏的感觉
- 光圈
- 快门（速度）：
	- 相机接收光线的持续时间
	- 持续曝光时间越短，收到的光线越少，画面越暗；持续时间越长，收到的光线越多，画面越亮
	- 一般快门 = 1 / （帧率*2）
		- 举例：如果帧率 = 30，那么快门 = 1/60

### 其他
- 直方图：
	- 数值：
		- x轴： 从左到右 代表 从暗到亮
		- y轴：像素密度
	- 简单理解：直方图里高的峰值，越靠右代表过曝，越靠左代表欠过曝
- 斑马纹：80%以下，注意此时人脸不要出现斑马纹画面就比较干净了
- 色温/白平衡：
	- 开尔文：k值越低，色温越暖；k值越高，色温越冷
	- 常见的色温参考：
