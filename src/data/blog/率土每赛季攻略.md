# 内政
- 吕蒙（深造）
	- 荆州、扬州范围内的所有地图建筑和城池补给范围增加1
	- 扬州范围内的城池部队征兵木材消耗额外降低40%
- 曹丕（深造）：势力交易比率提高 25.6%
- 何太后（深造）：主城补给范围己方领地所有资源产量提高300%
- 曹植（深造）：担任分成参军，土地产量提高21.1%
- 邓艾（深造）：势力屯田收益提高35%，城池补给范围额外提高17.6%
- 董白（深造）：担任分成参军，分成建筑产量增加10%
- 黄月英（深造）：建筑消耗降和时间降低9.8%
- 鲁肃：5-7级土地所在州内，每有一座己方城池，产量提升20-22
- 诸葛恪：势力执行资源获取（伐木、冶铁、屯粮）任务时，额外获取10%产量
- 贾允：5-7级地屯田有100%几率额外获取1个宝物材料
- 王允：城池预备兵回复速度增加 10%
